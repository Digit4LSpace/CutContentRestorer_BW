# Cut Content Restorer

Restores (most) cut content from BONEWORKS that was left disabled in the game scenes.

[Watch the Mod Trailer here](https://youtu.be/P_m8IfTcWus)

## Features

- Restores hidden objects across all Campaign/Sandbox/Arena levels
- Restores cut Eder22 gun settings
- My goal was to restore as much cut stuff as possible without breaking the level progression, so stuff like blocking geometry will not be enabled.

## Settings

- Cut and broken **Eder22 Gun Settings** is toggleable in MelonPreferences, can get in the way after a while lol

- **BlankBox** and **Fantasy Arena** both have toggles for the optimal performance

- **Throne Room** has a toggle for the **Exit Portal** that blocks the End Cutscene and Void Entities.

- **Backpack Straps** on the player can be toggled, being enabled can interfere with custom playermodels.

- **leftover NPC meshes** can be toggled.
